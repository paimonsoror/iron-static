## Shared contracts (all tasks code against these; M1-07 owns them)

Units and time: distances in meters, one tick = 1/30 s (`Ticks.TICK_RATE = 30`). One wave = 24 s = 720 ticks: spawn phase ticks 0-539, lull 540-719 (`Ticks.WAVE_TICKS`, `SPAWN_TICKS`, `LULL_TICKS`); `Ticks.from_seconds(s: float) -> int = roundi(s * 30.0)`. Wave numbers are 1-based; wave 1 starts at tick 0.

Classes (all `class_name`, all `RefCounted` unless stated), folder `src/sim/` unless stated:
- `math/Ticks` (static consts + `from_seconds`), `math/Rng` (PCG32), `math/Curves` (static pure functions, explicit parameters), `math/SinCosTable` (4096-entry LUT, `cos_i(idx: int) -> float`, `sin_i(idx: int) -> float`).
- `entities/EnemyStore`, `entities/ProjectileStore` (packed arrays, free list), `spatial/SpatialGrid`.
- `SimConfig` (`seed_value: int`, `sector: int = 1`, `tuning: SimTuning`, `enemies: Array[EnemyDef]`, `upgrades: Array[RunUpgradeDef]`, `ruleset: String = "standard"`, `debug_invulnerable: bool = false`).
- `SimWorld` with fields `tick: int`, `wave: int`, `wave_tick: int`, `level_hp: int`, `level_atk: int`, `enemies: EnemyStore`, `projectiles: ProjectileStore`, `grid: SpatialGrid`, `cinder: CinderState`, `stats: StatBlock`, `run: RunStats`, `events: SimEvents`; methods `step() -> void`, `is_over() -> bool`, `state_hash() -> String`, `debug_spawn_enemy(type_index: int, x: float, y: float) -> int`, `debug_spawn_bolt(x: float, y: float, vx: float, vy: float, damage: float) -> int`.
- `StatBlock` (final stat values as floats: `laser_output`, `cycle_rate`, `crit_chance`, `crit_mult`, `optic_range`, `hull_integrity`, `nano_repair`, `plating_pct`, `plating_flat`; static `from_base(cfg: SimConfig) -> StatBlock` fills level-0 base values; M2 replaces the filler with `StatResolver` but keeps this interface).
- `CinderState` (`hp: float`, `max_hp: float`, `band: int` 0-3, `alive: bool`; `apply_hit(raw: float, stats: StatBlock, tuning: SimTuning) -> float` implements the intake pipeline (GDD 02 section 12 steps 2-4 and 6) and returns damage actually taken).
- `RunStats` (`kills: int`, `kills_by_type: PackedInt32Array`, `scrap_earned: float`, `data_earned: float`, `damage_dealt: float`, `death_wave: int`, `death_cause: int` (enemy type index, -1 none)).
- `SimEvents`: ring buffer of 1024 events, each `(tick: int, kind: int, a: int, b: int)` in four packed arrays; `push(kind, a, b)`, `drain(cursor: int, out: PackedInt32Array) -> int`. Kinds (`SimEventKind` consts): `WAVE_STARTED`(a=wave), `WAVE_ENDED`(a=wave), `ENEMY_SPAWNED`(a=index, b=type), `SHOT_FIRED`(a=target index, b=crit 0/1), `ENEMY_HIT`(a=index, b=damage int), `ENEMY_KILLED`(a=index, b=type), `CINDER_HIT`(a=damage int, b=attacker type), `BAND_CHANGED`(a=old, b=new), `BOSS_SPAWNED`(a=index), `RUN_ENDED`(a=wave, b=cause).
- Step order inside `SimWorld.step()` (authoritative, determinism depends on it): (1) wave clock and wave-start spawn planning; (2) `SpawnSystem`; (3) `MovementSystem`; (4) rebuild `SpatialGrid`; (5) `LaserSystem` (target, fire, damage, kills); (6) `EnemyAttackSystem` (melee and lancer firing); (7) `ProjectileSystem`; (8) regeneration and `ExposureSystem` band update; (9) end-of-wave resolution if `wave_tick` reached 720; (10) death check; (11) `tick += 1`. A finished run (`is_over()`) ignores further `step()` calls.
- Data classes (hand-written, `src/data_defs/`, extend `Resource`, typed `@export`-free vars): `EnemyDef`, `RunUpgradeDef`, `SimTuning`. Generated `.tres` in `src/data_gen/`. Loader `src/core/sim_config_loader.gd` (`SimConfigLoader.load_default(seed_value: int) -> SimConfig`) is outside `sim/` because it calls `load()`.
- Enemy type index = row order in `enemies.csv`: 0 `skitter`, 1 `dart`, 2 `walker`, 3 `lancer`, 4 `boss_hulk`.

## M1-01 Ticks and Rng (PCG32)
- **Goal:** time constants and a deterministic RNG that every sim system uses.
- **Size:** S. **Group:** A. **Depends on:** none.
- **Files:** `src/sim/math/ticks.gd`, `src/sim/math/rng.gd`, `tests/unit/sim/test_rng.gd`, `tests/unit/sim/test_ticks.gd`.
- **Inputs:** `docs/TECH_ARCHITECTURE.md` section 2.2 (tick rate, ticks not seconds), 2.3 (PCG32, sub-streams, no global RNG); `docs/design/02_combat_in_run.md` section 6 (24 s wave).
- **Spec:** `Rng` is PCG32 (64-bit state, odd increment) implemented with integer ops; GDScript `int` is signed 64-bit and `>>` is arithmetic, so mask after shifts to emulate unsigned 32-bit output. API: `_init(seed_value: int, stream_id: int = 0)`, `next_u32() -> int`, `next_float() -> float` ([0,1), 24-bit resolution), `range_int(lo: int, hi_inclusive: int) -> int` (unbiased rejection), `chance(p: float) -> bool`, `get_state() -> PackedInt64Array`, `set_state(s: PackedInt64Array)`, `static derive(seed_value: int, stream_name: String) -> Rng` (seed XOR FNV-1a-64 of the name, so adding a stream never changes another). Streams used later: `spawn`, `loot`, `crit`, `draft`, `effects`.
- **Acceptance:**
  - `Rng.new(42, 54)` (seed 42, sequence 54, standard `pcg32_srandom(42, 54)` seeding) yields first outputs `0xa15c02b7 0x7b47f409 0xba1d3330 0x83d2f293 0xbfa4784b 0xcbed606e` (values from the PCG reference demo; if they disagree with the reference C implementation, trust the reference and fix the test vector in the commit message).
  - Same seed and stream give identical 10,000-value sequences; different stream names give different sequences; save/restore state continues the same sequence; `range_int(0, 9)` over 100,000 draws has every bucket within 5% of 10,000; `chance(0.0)` never true, `chance(1.0)` always true.
  - `Ticks.WAVE_TICKS == 720`, `SPAWN_TICKS == 540`, `LULL_TICKS == 180`, `from_seconds(0.08) == 2`.

## M1-08 SpawnSystem
- **Goal:** waves spawn the right number and mix of enemies at the right times and angles.
- **Size:** L. **Group:** D. **Depends on:** M1-07, M1-04.
- **Files:** `src/sim/systems/spawn_system.gd` (and `src/sim/systems/wave_plan.gd` if over 300 lines), `src/sim/math/sin_cos_table.gd`, `tests/unit/sim/test_spawn_system.gd`.
- **Inputs:** `docs/design/02_combat_in_run.md` section 6 (spawn count, slot rule, spawn times, angles and flank groups, boss waves, stale rule is elsewhere); `docs/design/03_enemies_waves_tiers.md` sections 5 (weights, ramp, rejection), 7 (boss cadence), 1.1 (`first_wave`); `docs/design/08_mvp_scope.md` section 1.2.
- **Spec:** at the first tick of a wave build a plan (`wave_plan`) using the `spawn` RNG stream: `N = slots_for_wave(wave)`; boss waves (`wave % boss_interval == 0`) use `floor(boss_slot_fraction * N)` normal slots plus one `boss_hulk` at tick `Ticks.from_seconds(boss_spawn_s)` (also push `BOSS_SPAWNED`). Draw types by weight among types with `first_wave <= wave`, effective weight `weight * min(1, (wave - first_wave + 1) / ramp_waves)`; boss type never drawn. Interpretation of the slot rules (document in the file header): a draw is accepted if `slots <= remaining + slot_overflow`; a rejected draw is redrawn up to `reject_limit` times, then a skitter is used; filling stops when remaining slots are 0. Spawn tick of an enemy starting at slot index `i`: `t = spawn_seconds * (i + u) / N` seconds with `u` uniform [0,1), converted with `Ticks.from_seconds`, sorted by time. Angles: walk enemies in time order; each unassigned enemy with probability `flank_fraction` starts a group of `range_int(flank_min, flank_max)` consecutive enemies sharing a center angle plus uniform +-`flank_half_angle_deg`; others uniform. Angles are integer indices into `SinCosTable` (4096 entries); position = `arena_radius * (cos, sin)`. Alive caps: if alive normal enemies are at `alive_cap_normal` or bosses at `alive_cap_boss`, the spawn waits (queue, retried every tick, never dropped, metric `run.spawn_throttled` incremented). Spawning uses `SimWorld.spawn_enemy`.
- **Acceptance:** tests (default config, fixed seed): wave 1 plan has 8 slots, all skitters; waves 1-3 contain no dart; over waves 4-60 the count of slots per wave equals `N(w)` (sum of slots, overflow at most 2); lancers appear only from wave 6 and walkers from wave 8; wave 10 spawns exactly one `boss_hulk` at tick 60 and `floor(0.6 * 15) = 9` normal slots; wave 20 same pattern; spawn ticks all lie in [0, 539]; over 2,000 waves of flank sampling about 40% (+-5%) of enemies belong to groups; the same seed gives the same plan; with `alive_cap_normal` forced to 5 in a test config no more than 5 normals are ever alive and all planned enemies eventually spawn.
