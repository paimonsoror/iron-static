## M2-01 BigNum
- **Goal:** the number type for currencies and costs.
- **Size:** M. **Group:** A. **Depends on:** none.
- **Files:** `src/sim/math/big_num.gd` (`class_name BigNum extends RefCounted`), `tests/unit/sim/test_big_num.gd`.
- **Inputs:** `docs/TECH_ARCHITECTURE.md` section 3 (mantissa in [1,10) plus `int` exponent, operations, string serialization); `docs/design/04_economy.md` section 5 (rounding and floor rules).
- **Spec:** immutable value class with `m: float` (0 or in [1,10)) and `e: int`; zero is `m = 0, e = 0`. Constructors `static zero()`, `from_float(x: float)`, `from_int(x: int)`, `parse(s: String)` (accepts `"123"`, `"1.2345e456"`, `"0"`). Operations returning new values: `add`, `sub` (clamps at zero, name it `sub_floor0`), `mul`, `mul_float`, `div`, `pow_float(p: float)`, `floor_value()`, `min`, `max`; comparisons `cmp(other) -> int`, `lt le gt ge eq`; `log10() -> float`; `to_float() -> float` saturating at 1.7976931348623157e308; `to_text() -> String` canonical form (`"0"`, or mantissa with at most 12 decimals and trailing zeros trimmed, then `e` and the exponent, e.g. `1.2345e456`; values below 1e15 may print as plain integers). Exponent difference above 17 in `add` returns the larger operand. Never produce NaN: operations on invalid input push an error and return zero.
- **Acceptance:** tests: round-trip `parse(to_text(x))` equals `x` for 1,000 random values across exponents -300..+3000; add/sub/mul/div agree with float64 within 1e-12 relative error for values within double range; `sub_floor0(5, 10)` is zero; comparisons are total-order consistent on a sorted list of 200 values; `from_float(1e308).mul(from_float(1e10)).to_text()` is `1e318`; `to_float` of `1e400` is the saturated maximum; `parse("garbage")` returns zero and records an error; 100,000 additions complete in under 1 s on the dev machine (informational).

## M2-02 NumberFormat
- **Goal:** the GDD number display rules.
- **Size:** M. **Group:** A. **Depends on:** M2-01.
- **Files:** `src/core/number_format.gd` (`class_name NumberFormat`, static), `data/number_suffixes.csv` (columns `exp,suffix`; imported or read via `CsvTable`), `tests/unit/core/test_number_format.gd`.
- **Inputs:** `docs/design/04_economy.md` section 5 (rules 1-6, settings, affordability coloring is UI); `docs/TECH_ARCHITECTURE.md` section 3 (formatting paragraph).
- **Spec:** `static format(value: BigNum, style: int = SHORT) -> String` with styles `SHORT` (0..999 integer floor; suffixes `K M B T Qa Qi Sx Sp Oc No Dc` at 1e3 to 1e33; always at most 3 significant digits, **floored never rounded up**, trailing zeros trimmed: `15.0K` becomes `15K`; at 1e36 and above scientific `1.23e45`), `SCIENTIFIC` (`1.23e4` from 1,000 up), `ENGINEERING` (exponent a multiple of 3, `12.3e3`). Also `format_float(v: float, max_decimals: int) -> String` for stat values (1.44, 12), `format_percent(fraction: float)` (1 decimal below 10%, integer at or above), `format_mult(v: BigNum or float)` (`x1.25`, `x12.4`, `x1.24K`), `format_time(seconds: int)` (`45s`, `12m 30s`, `3h 05m`, `1d 4h`). A small cache keyed by the value text avoids string churn.
- **Acceptance:** table-driven tests, each row `(input, style, expected)`: `847 -> "847"`, `999 -> "999"`, `1000 -> "1K"`, `1234 -> "1.23K"`, `12400 -> "12.4K"`, `15000 -> "15K"`, `847000 -> "847K"`, `999999 -> "999K"` (floored), `1e6 -> "1M"`, `1e12 -> "1T"`, `1e33 -> "1Dc"`, `1.5e35 -> "150Dc"`, `1e36 -> "1e36"`, `1.23456e45 -> "1.23e45"`, `0 -> "0"`; percent `0.0734 -> "7.3%"`, `0.25 -> "25%"`; mult `1.25 -> "x1.25"`, `12.4 -> "x12.4"`; time `45 -> "45s"`, `750 -> "12m 30s"`, `11100 -> "3h 05m"`, `100800 -> "1d 4h"`; engineering `12345 -> "12.3e3"`; the suffix table file has 11 rows and matches the code.

## M2-03 StatResolver
- **Goal:** Type D and Type C stat formulas and the upgrade table as one resolver that replaces `StatBlock.from_base`.
- **Size:** M. **Group:** A. **Depends on:** none (uses M1 data classes).
- **Files:** `src/sim/stat_resolver.gd`, `src/sim/external_mults.gd` (`RefCounted`, per-stat multiplier and additive fields defaulting to 1.0 and 0.0; used later by firmware, Lab, patches), edit `src/sim/stat_block.gd` (keep `from_base`, add `static from_resolver`), `tests/unit/sim/test_stat_resolver.gd`.

- **Spec:** `StatResolver.resolve(defs: Array[RunUpgradeDef], run_levels: PackedInt32Array, foundry_levels: PackedInt32Array, foundry_f: PackedFloat64Array, mults: ExternalMults) -> StatBlock`. Type D: `base * run_factor(L, p) * foundry_mult(F, f) * mult` with `L` clamped to `l_cap`. Type C: `clamp(base + step * min(L, l_cap) + f_inc * min(F, F_cap), 0, hard_cap)` (empty `hard_cap` means none); multiplier-type stats (`scrap_yield`) multiply by the external multiplier after clamping, additive stats (`reinvest`, `crit_chance`, `plating_pct`) add external bonuses before clamping. `foundry_f`/`foundry_levels` default to empty (all zero) in M2 and are supplied by M3. `StatBlock` gains `scrap_yield: float` and `reinvest: float`. **Milestone ring helper** `StatResolver.levels_to_next_milestone(level: int) -> int` (distance to the next multiple of 25, used by the UI gold ring).
