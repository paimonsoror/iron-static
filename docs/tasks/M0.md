## M0-05 Test wrapper `tools/test.ps1` with output parsing and canaries
- **Goal:** agents run tests through one command that fails on script errors, zero tests, or any failure, even when Godot exits 0.
- **Size:** M. **Group:** D. **Depends on:** M0-04.
- **Files:** `tools/test_runner.py` (stdlib-only Python, the real logic, also used by CI), `tools/test.ps1` (thin wrapper: dot-source `_common.ps1`, call `Find-Python` + `test_runner.py`, forward exit code), `tests/canary/test_canary_fail.gd` (always fails, suite named `TestCanaryFail`), `tests/canary_parse/test_canary_parse.gd` (contains a deliberate syntax error), `tools/test_allowlist.txt` (regex lines for known-benign output; initially empty with a comment). The parser self-test is `test_runner.py --self-test`.
- **Inputs:** `docs/TECH_ARCHITECTURE.md` section 10.1 (wrapper requirements: import step, run, parse output or JUnit XML, fail on `SCRIPT ERROR`, `Parse Error`, `ERROR:`, or zero tests), `docs/setup/gdunit4.md` from M0-04.
- **Behavior of `test_runner.py` (args: `--godot <exe> --project <dir> [--path res://tests/unit] [--suite <name>] [--canary]`):**
  1. Run `--headless --path <project> --import`; if output matches an error pattern (`SCRIPT ERROR`, `Parse Error`, `ERROR:` not matched by the allowlist) exit 2.
  2. Run GdUnit4 CLI with a fresh report dir under `build/test/`; capture full output to `build/test/last_output.txt`.
  3. Parse the JUnit XML in the report dir (`results.xml` or the file GdUnit4 documents) for `tests`, `failures`, `errors`, `skipped`; also re-scan the captured output for the error patterns.
  4. Exit codes: 0 pass; 1 any failure or error in tests; 2 script/parse error in output; 3 zero tests executed; 4 tool failure (Godot missing, no report). Always print `TEST SUMMARY: tests=N failures=F errors=E skipped=S exit=X` as the last line and write `build/test/summary.json`.
  5. `--canary` runs the two canary suites and **succeeds (exit 0) only if** the first canary yields exit 1 and the second yields exit 2 (or 1); prints `CANARY OK`.
- **Acceptance (all objectively checkable):**
  - `.\tools\test.ps1` exits 0 and prints `TEST SUMMARY: tests=2 failures=0` (matches M0-04).
  - `.\tools\test.ps1 -Canary` exits 0 and prints `CANARY OK`.
  - Temporarily break `tests/unit/test_smoke.gd` with a syntax error: `.\tools\test.ps1` exits non-zero (2 or 3), never 0. Revert.
  - Temporarily point `--path` at an empty folder: exit 3. Revert.
  - `py -3.12 tools/test_runner.py --self-test` runs 5+ parser unit checks on canned output strings (pass, failure, parse error, zero tests, allowlisted error) and exits 0.
