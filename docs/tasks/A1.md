## Rules specific to A1

- **Claude-synthesized, original, deterministic.** All audio is produced by `tools/audio_gen/` (Python 3 + numpy/scipy/soundfile in `tools/audio_gen/.venv`, pinned in `tools/audio_gen/requirements.txt`). Fixed seeds: re-running `tools\audio_gen.ps1` must reproduce identical files (checked by hashing two runs). No samples from any existing recording.
- **IP rules (hard, extend 07 s7):** no melody, motif or chord progression resembling any film theme; no repeating anvil or metal-clank ostinato in an odd meter (13/16, 13/8, 7/8 and the like) as a hook: the industrial layer is in 4/4 (or 6/8) at 84-96 BPM with syncopation; no heavy synth march; never name a film franchise in files, code, comments or docs.
- **Swappable slots.** Every sound is a row of `assets/audio/slots.csv` (`id,file,bus,volume_db,pitch_var,voice_cap,cooldown_ms`). A commissioned pack replaces files and edits rows; no code change. Audio assets must NOT live in a `.gdignore`d folder; CSVs next to them use the `keep` importer (like `assets/art/slots.csv`).
- **Presentation only.** Audio code lives in `src/audio/`, never touches `src/sim`, `src/meta`, `src/save`, `data/*.csv`, and never uses the sim `Rng` (pitch jitter has its own `RandomNumberGenerator`). `git diff --stat -- src/sim src/meta src/save data` stays empty and `tests/sim/test_replay.gd` goldens are unchanged.
- **Formats.** SFX: 16-bit WAV mono, 44100 Hz (the project mix rate, Godot default). Music layers: OGG Vorbis stereo, 44100 Hz, equal length (8 bars of 4/4 at 90 BPM = 940800 samples), loop set in code (`AudioStreamOggVorbis.loop`). Budget: sketch pack under 6 MB; game audio under 8 MB until M6.
- **Lifecycle.** `AudioDirector` exposes `pause_all()` / `resume_all()`; the main scene's lifecycle owner calls them. Audio code never hooks the lifecycle itself.
- Implementation choices not in 07 s7 are marked **(impl)** in the commit message.

## A1-01 Sound sketch for approval (the gate input)
- **Goal:** let the user judge the sound before the full set is made.
- **Files:** `docs/playtests/a1/*` (preview, layer loops, 12 core SFX, `sfx_reel.wav`, `analysis.json`, `A1-01_sketch.md`).
- **Spec:** a ~64 s preview of the ambient to industrial build (drone/pad -> pulse -> industrial percussion -> boss lead), each layer as a separate loop, the 12 core SFX (`sfx_laser_shot` soft and non-fatiguing, `sfx_hit_metal`, `sfx_crit`, `sfx_enemy_death_small`, `sfx_enemy_death_heavy`, `sfx_player_hit`, `sfx_wave_start`, `sfx_boss_warn`, `sfx_upgrade_buy`, `sfx_ui_tap`, `sfx_ui_deny`, `sfx_death`) and one reel playing all SFX in sequence. `A1-01_sketch.md` lists each file with its recipe and measured loudness.
- **Acceptance:** total size under 6 MB; per file peak/RMS/LUFS-ish, DC offset and clipped-sample count reported; no clipping; loop seam jump ratio <= 1.5 for every layer (also on the decoded OGG); decoded layer length equals the source length.

## A1-02 Audio generation tooling
- **Goal:** reproducible offline synthesis.
- **Files:** `tools/audio_gen/{dsp,sfx,music,analyze,render}.py`, `requirements.txt`, `.gdignore`, `tools/audio_gen.ps1`, CLAUDE.md commands row, `.gitignore` entry for the venv (existing `.venv/` rule).
- **Spec:** building blocks: oscillators (band-limited saw/square, tri, sine, noise), ADSR, one-pole and biquad LP/HP/BP with sweeps, FM, drive and bitcrush, delay and Schroeder reverb, look-ahead limiter, loop-safe rendering (tail wrap + tiled effect processing). Deterministic: fixed seeds, pinned libraries, Ogg serial pinned. Outputs to `assets/audio/` and `docs/playtests/a1/`.
- **Acceptance:** two consecutive runs give byte-identical audio files; `tools\audio_gen.ps1` exits 0.

## A1-03 Runtime plumbing: buses, slots, directors, settings
- **Goal:** everything needed to play sound, with nothing wired yet.
- **Files:** `default_bus_layout.tres`, `assets/audio/slots.csv`, `assets/audio/music_layers.csv` (+ `.import` keep files), `src/audio/*` (`AudioBuses`, `AudioSlot`, `AudioSlots`, `VoiceGate`, `BuyPitchRamp`, `AudioSettings`, `AudioDirector`, `SfxPool`, `MusicDirector`, `MusicIntensity`, `MusicLayerRule`, `MusicState`), edit `src/core/game.gd` (`Game.audio`), `tests/unit/audio/*`.
- **Spec:** Master (limiter) -> Music (compressor side-chained to SFX), SFX, UI. `play_sfx(id, pitch_jitter, semitones)` enforces voice caps and cooldowns; `sfx_upgrade_buy` repeat buys step up in pitch (+0.5 semitone per consecutive buy, cap +5, reset after 450 ms or on release); music layers in one `AudioStreamSynchronized`, volumes from `MusicIntensity` with linear fades.
- **Acceptance:** unit tests for slot parsing (incl. a BOM-prefixed CSV), voice cap and cooldown, buy pitch ramp, `MusicIntensity` targets and fade step, settings and bus layout; headless import of all audio files has no errors; lint and tests green.

## A1-04 Gate preparation and report

## A1-GATE User approval of the sound sketch (not a task)
- **Who:** the user. **Inputs:** `docs/playtests/a1/`. **Outcomes:** (a) approved: phase 2 starts; (b) changes: the main agent turns the notes into recipe edits (`tools/audio_gen/`) and re-renders; (c) direction change: 07 s7 and this file are revised first.
- Questions to answer: does the build from ambient to industrial feel right; is the laser tick tolerable at 20+ shots per second; are the boss warn and death sounds the right weight; is the music too busy or too quiet; any sound to cut or add.
